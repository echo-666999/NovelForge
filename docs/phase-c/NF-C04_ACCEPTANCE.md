# NF-C04 Prompt、模型路由及文风配置版本验收

日期：2026-10-24。授权范围为 NF-C04；没有调用真实模型、推进 C05/C06 或处理中文分词。

## 交付与契约

- 三组稳定身份和不可变版本：`prompt_templates/prompt_versions`、`model_routes/route_versions`、`style_profiles/style_versions`。编辑（包括草稿）派生新版本，以 `expected_version` 防止覆盖并发编辑。身份键、阶段和语言不能原地改写。
- 生命周期：draft → tested → published → retired。离线回归失败保留 draft 与失败证据；发布必须已有相同内容摘要的通过记录。发布更新默认指针；退役清空指向自己的默认指针，历史引用保留。数据库触发器禁止覆盖正文、删除历史、跨状态跃迁及把草稿设为默认。
- Prompt 包含用途、正文、变量 Schema、输出 Schema、能力要求、固定样例和版本说明。仅支持 `{{json:变量名}}`，JSON 转义且不递归求值；缺变量、额外变量、类型不符、未知占位符和未转义占位符均阻塞。禁止把模板当作 Blade/PHP 执行。转义是数据编码，不声称可完全防御自然语言提示注入。
- 输出与变量 Schema 复用 C03 有界子集（object/array/string/integer/boolean/null，禁止额外字段）；不支持完整 JSON Schema。`test.echo` 发布还要求 `text` 字符串对象契约。
- 固定 Prompt 样例验证输出结构、必需事实片段和渲染字节数。文风样例验证人工标注分数对应的阈值、禁用表达与预期通过结果。记录 `offline_fixture`、`real_model_verified=false` 和 `actual_tokens=null`。不把样例输出当成真实生成质量、语义事实验证或 Token 实测。
- 路由引用已发布 Prompt/文风、主模型能力版本及至多两个明确批准且有原因的备用模型。发布重新检查引用是否退役、阶段/语言及声明容量/结构化能力。当前只有 `offline_fake` 可通过；`production` 可保存草稿，但回归以 `CAPABILITY_UNVERIFIED` 阻塞，不把未验证能力标成 available。
- 文风包含视角、语气、节奏、描写偏好、禁用表达、授权样例、题材、评分维度及整数阈值、最大修订轮次。降低阈值必须保存新版本与原因，旧版本、回归记录和运行快照不变。此处评分为配置验证；不替代 PRD 文学验收的 1–5 分标准，也不自动改写 A05 的通过线。

## 与运行、请求的连接

`GenerationService::start` 的测试支架可传 `configuration`：`route_version_id` 或 `route_key` 二选一，另带 `variables`。按键解析默认版本只发生在启动时，并与配置发布使用同一配置锁；原幂等命令始终重放首次结果。

运行冻结完整路由、Prompt、文风、输入变量、渲染结果、主备模型真实标识、供应商配置版本、声明容量及验证状态，纳入 `input_hash`。请求持久保存实际 route/prompt/style 版本、配置摘要与实际模型版本。供应商新版本不替换旧运行的冻结配置；最新供应商停用状态仍能阻止发起请求。

`GenerationService::claim` 可在旧尝试 failed/deferred/blocked 后，携带 `retryOf`、批准清单中的模型版本和切换原因创建下一尝试；保持 C01 三次尝试上限。禁止在活动尝试切换、不批准的模型切换，以及结果 pending/unknown 时替代或普通重试。切换不复用旧模型检查点，旧请求和失败产物保留；每次尝试固定自己的实际模型身份。网关拒绝输入、模型与冻结选择不一致的请求。

价格/预算仍属于 C05：快照明确 `price_version_id=null`、`price_status=unknown`，未创建伪造价格引用或费用记录。语言质量实测、真实容量与 Token 计量均未完成。真实调用仍由 C03 testing + fake 门禁关闭。C01 无配置的旧测试图继续兼容；它不是生产配置绕过入口。

## 接口及后台

同源会话、管理员授权、CSRF 沿用已有策略。GET `/api/v1/configurations/{prompt|route|style}` 返回分页版本、内容、回归和引用运行数，支持 key 搜索、stage/language/status/page 筛选。POST 后缀 `save/test/publish/retire`，需要 `Idempotency-Key`；原生表单使用 `command_key`。保存传完整配置；其余动作仅传 `version_id`。错误沿用 A04 envelope。

- `/admin/prompt-templates`：新建、复制编辑、变量与样例回归、发布、退役、版本比较、摘要、引用运行数。
- `/admin/model-routes`：主备策略 JSON、模型/Prompt/文风引用、参数、批准原因、离线回归及发布。供应商密钥管理继续在 C03 `/admin/providers`。
- `/admin/style-profiles`：文风和评分策略、标注样章、测试/比较/发布/退役。

三个页面提供字段完整的可编辑 JSON 示例、历史只读详情、分页/筛选、状态和空态。版本比较并列显示正文、阈值与回归，不宣称有真实模型对比。当前为后台配置编辑器；未开展可视化浏览器、移动端人工验收。

## 验收与证据

最终自动化结果见同目录 `NF-C04_TEST_RESULTS.json`；定向结果见 `NF-C04_TARGET_TEST_RESULTS.json`。覆盖：

1. 命令幂等重放、冲突键、陈旧版本、数据库正文不可变和直接发布/默认指针绕过。
2. 缺变量、不安全占位符、输出类型错误、事实片段遗漏及失败回归不能发布；JSON 转义不递归解释输入。
3. 输出阶段契约不匹配、真实能力未验证、容量不足和引用退役均阻塞。
4. 新 Prompt/文风发布与退役不修改旧运行；默认路由仅影响新运行；幂等重放仍返回旧快照。
5. 批准主备切换新建尝试，实际模型和请求证据分开；未批准切换、活动尝试切换、unknown 替代及错误输入被拒绝。
6. 供应商配置轮换保持冻结版本，停用阻止新请求。
7. 管理员/访客/非管理员边界，三个页面 HTTP 渲染、API 操作、Livewire 筛选比较及非法 JSON 表单。
8. 新表与新增字段 PostgreSQL 中文备注；全量测试还覆盖已有业务、隔离防护、队列恢复及迁移回滚。

开发库增量迁移、备份与备注核查见 `NF-C04_MIGRATION_RESULT.json`。备份仅做归档清单检查，未进行实际恢复演练。

## 修复记录及边界

初次运行发现两个测试把 JSON 对象的键顺序视为内容差异，已改为比较对象值（没有排序列表掩盖差异）。重复测试暴露 PostgreSQL 清表后函数仍存在，迁移已用 `CREATE OR REPLACE FUNCTION`；修复后重新验证。默认路由互斥校验曾使用当前框架不存在的规则，已改为显式互斥检查；最终完整回归覆盖此修复。事实片段检查已改为在实际字符串值中匹配，避免将 JSON 字段名或转义表示误判为正文。

A02、DEC-01/02/05 仍是实际部署/供应商/预算前置事项；本轮没有新增阻塞离线配置交付的待决事项。没有真实模型调用、生产 Worker 启动、章节正文生成、文学质量或前十章/百章回收验收；不能用 C04 离线通过替代它们。
