## 追踪与审计约束

新增 `run_traces` 保存每个运行的根 UUID，新增 `audit_events` 保存追加事件。HTTP 中间件生成服务端操作 UUID，以 X-Trace-Id 返回；不信任客户端传入的追踪号。API错误响应也含 trace_id。操作结束清除 PostgreSQL 连接上下文，避免长驻进程串号。

数据库触发器把运行、步骤、请求、产物、恢复决定、隔离证据、重提取结果、核销、费用流水及供应商/模型/Prompt/路由/文风/价格/预算版本关联到同一根运行；每次HTTP操作另保留 operation_trace_id。后台任务通过持久 run_id 取得根追踪号，无需页面会话持续存在。未绑定运行的配置操作保留自己的操作链。

审计与成功业务变更在同一事务中提交；业务回滚不留下伪成功事件。HTTP拒绝命令另记稳定错误码/HTTP状态，不保存异常原文。高风险事件保留版本、哈希、状态及原因；原因优先取显式HTTP操作字段，完整表单、认证密钥、请求正文和模型正文不复制到审计快照。记录与追踪映射均由数据库触发器禁止UPDATE/DELETE；这不是对数据库超级用户的防篡改保证，A02最小权限仍待完成。

已有运行升级时生成 `origin=historical_backfill` 追踪号；既有业务历史不改写，不补造旧审计事件。未实施的 review/Canonical Commit 尚无真实实体，不能宣称它们已加入追踪链。

## 私有证据与截断

供应商完整脱敏请求/响应继续保存在 C03 的数据库加密证据中，不复制到公开磁盘。下载接口只接受类型及数字ID，不接受文件路径；每次复核管理员、小说归属、运行归属及内容哈希，返回附件、private/no-store及nosniff；成功读取追加审计。

产物摘要限制500个Unicode字符，显式返回 `truncated` 和完整受控下载链接；页面进行HTML转义。摘要截断不表示供应商响应缺失。审计只存白名单元数据与引用，产物事件可以直接跳转完整下载。审计导出明确为当前筛选页，包含page/total，不冒充全部历史。

## 接口

- GET `/api/v1/runs`：列表、各状态计数、分页、生产启动可用性false。
- GET `/api/v1/novels/{novel}/runs/{run}`：详情，`request_page`选择50条请求页。
- GET `/api/v1/novels/{novel}/runs/{run}/artifacts/{object}`：完整产物附件。
- GET `/api/v1/novels/{novel}/runs/{run}/requests/{object}/evidence/{request|response}`：完整脱敏证据附件。
- GET `/api/v1/audit`、`/api/v1/audit/export`：追加审计读取/当前页导出。
- GET `/api/v1/operations/health`：过期租约、阻塞运行、未知费用和待投递意图；基础设施可用性保持unknown/unverified。

API沿用同源会话；没有匿名下载、写审计、重写历史或真实模型启动接口。列表与审计ID使用字符串；时间按ISO8601 UTC输出。阶段耗时仅反映当前持久尝试的开始/最后更新时间，不声称已实现独立的模型网络耗时指标。
