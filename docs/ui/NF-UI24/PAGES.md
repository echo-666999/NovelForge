# NF-UI24 配置页面复核矩阵

日期：2026-10-28。依据现有 Filament 页面、DESIGN.md、NF-UI23；本轮继续使用 Interface Design。范围为“配置与运维”六页；只调整剩余展示，不扩展配置业务。

| 菜单 / 路由 | 当前默认内容 | 新增 / 查看方式 | 本轮处理 |
| --- | --- | --- | --- |
| Prompt 模板与发布 / prompt-templates | 配置版本列表 | 正常大小新建按钮、原生编辑/详情/比较弹窗 | 复核既有 NF-UI23 源码，原配置回归覆盖；不改文件 |
| 供应商与模型 / providers | 供应商、模型能力版本列表 | 原生弹窗，保存仍走既有安全 POST | 同上，不改密钥处理 |
| 模型主备路由 / model-routes | 路由版本列表 | 新建、复制、详情/比较弹窗 | 同上，不改版本引用 |
| 文风与评分策略 / style-profiles | 策略版本列表 | 新建、复制、详情/比较弹窗 | 同上，不改评审策略 |
| 价格与原子预算 / billing | 价格版本、预算政策、费用账本列表 | 新建价格版本、新建预算政策、录入对账凭证分别按需加载；版本/账本证据只读弹窗 | 本轮整改及浏览器验收 |
| 审计与系统健康 / audit-center | 健康摘要、筛选及审计记录表格 | 健康完整投影、审计完整记录用只读弹窗查看 | 本轮整改及浏览器验收；不增加新建审计按钮 |

审计为只追加的系统记录，不能为统一布局添加人工新建、编辑或删除审计功能。运行、提取、评审等工作流页面不属于配置目录，本轮不改造其业务交互。

## 列表与弹窗标准

- 动作复用 nf-config-actions 和 Filament 按钮，高40px，宽度随文案，同组12px间距，窄屏自然换行。
- 编辑复用 NF-UI23 的 x-nf.editor-modal 与 NF-UI06/07 字段树；只渲染当前所选编辑器，不把 JSON 当默认编辑界面。
- 成功后关闭回表；失败保留字段并聚焦当前弹窗内错误；取消、Escape、关闭不保存，字段及原幂等身份继续保留供重试。
- 价格/政策目录保留原最近100条范围；费用筛选收纳于账本筛选区，仅影响原费用查询，不声称过滤价格/政策目录。费用分页、导出参数、金额字符串和未知费用空值保持。
- 只读详情从既有授权目录或当前审计查询页中选择，不通过客户端任意ID直接扩大读取范围；完整投影继续使用既有逐字段只读组件。
