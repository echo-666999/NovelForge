## 共同实现规则

复用UI06的Section/Field/story-select/Table与小说上下文；沿用UI04锁定类型树、扁平标量绑定和类型化value-table。短字段桌面两列、手机一列，长正文/范围与证据跨列；普通属性不再套独立边框，列表/容器保留轻边界。所有内容转义，宽表有具名局部滚动。

ProductionSchemas从实际Planning/Review/Extraction/Patch契约映射。已知属性不可任意改名；可选项明确增加/移除，有序数组不排序。高级JSON仅折叠导入，解析成功后映射，失败保留原树。未知节点转通用类型编辑器保留；无法无损转成既有服务输入时明确阻止，UI11未关闭。正文即使以JSON符号开头也仍为正文。

HasProductionChoices采用白名单和现有服务授权，书、分支、正文/提取、任务与阶段范围分别限制，不接受浏览器提供表名或属性路径。EditsProductionPayloads保存时重新读取当前树，错误值不得悄悄回退到旧JSON。业务服务最终复验版本、来源、预算和许可。

WritesProductionCommands在当前页面会话内冻结原载荷和幂等键，动作身份包括策略发布/退役；同一输入重复保存沿原命令。需要相同内容的下一次新操作须明确“开始新一轮操作”。不宣称页面刷新/丢失完整Livewire状态后仍可恢复原响应；载荷不符由服务拒绝，不能绕过并发检查。账本表单同样缓存当前输入的命令键。
