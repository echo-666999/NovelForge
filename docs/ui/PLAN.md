## 4. 产品与视觉方向

- 使用者：单人作者，反复在规划、候选正文、证据、评审、修订和正式提交间切换。
- 核心动词：找到当前书与章、编辑候选内容、定位冲突、核对证据、执行明确动作。
- 领域词：原稿、卷章、场景、批注、伏笔、稿本版本、正式基线、证据链。
- 色彩来源：纸白、稿纸灰、铅笔墨、书签靛蓝、校对朱红、归档深绿。纸白/墨色负责阅读；靛蓝为唯一交互强调；红绿只表达语义。
- 特征：小说上下文条 + 候选/正式身份标签 + 带来源的章节证据。分别贯穿工作台、正文、提取、评审、记忆页面，而非靠装饰体现“小说工具”。
- 排除三个默认：无上下文的菜单堆叠→书内工作区；整段 JSON 编辑→类型化字段；一屏技术说明→任务优先、诊断按需展开。
- 方向：适中密度的中文编辑工作台，正文安静、操作清晰、证据可追溯。优先轻边界与层次，不加宣传式大图、玻璃效果、装饰图表。

沿用 PRD §22.1 的五组，固定此顺序，不能由页面创建顺序或字符串字典序决定。所有常驻页面归组，不允许游离顶层菜单。页面内的页签不能假扮左侧第三级树。

| 分组 | 全局常驻入口 | 书内二级入口 / 附属页 |
| --- | --- | --- |
| 创作工作台 | 创作总览、小说库 | 小说工作台、正文编辑；后续业务实现后的章节目录与连续阅读 |
| 故事管理 | 当前小说故事管理入口（无书时提示选择） | 原始要求、蓝图、卷弧与章场景、世界与人物、时间线与知识、伏笔主支线与终局 |
| 生产与质量 | 生成运行、正文提取与硬约束、评审中心、受限修订、正式提交、上下文检查 | 运行详情/恢复；候选规划与正文从小说进入；验收入口仅业务具备后启用 |
| 检索与记忆 | 分层记忆、正式记忆与索引、检索实验室 | 记忆来源、索引任务、评测与诊断 |
| 配置与运维 | Prompt、供应商模型、模型路由、文风与策略、费用预算、审计健康 | 实施状态移入“关于与实施状态”次级动作；导出/备份/设置待对应业务实现 |

首页不再出现三个无分组顶层项。三个页面在“生产与质量”中按提取→评审→修订排序。审计“配置与运维”、模型等“系统配置”、实施状态“系统管理”统一为“配置与运维”；现有“创作管理”拆回故事管理、检索与记忆、生产与质量。

故事页优先绑定小说 Resource 路由，不为凑导航复制实体页面。现有带 `novel` 查询参数的生产页暂保留原 URL，增加统一小说选择器和上下文。切书清除章、版本、角色、运行等旧选择；不可沿用另一书 ID。深链接失效显示错误或选择书，不能静默换书。

全局配置页没有“正式基线”属性，不硬塞虚构小说；书内页固定显示书名、章范围、正式/候选、当前实际基线。全局页标题与说明不得挤占主要操作区。

## 6. JSON 字段交互规范

存储类型不决定 UI 控件。写入仍经原服务，表单只负责结构化数据映射，不新增直接 JSONB update。

| JSON 内容 | 默认 UI | 编辑规则 |
| --- | --- | --- |
| 固定属性对象 | Section/Fieldset + 对应 Input/Select/Toggle/Textarea | 一属性一字段；必填、范围、单位与错误在字段旁 |
| 有序对象数组 | Repeater，复杂列表用子表/抽屉 | 新增/删除/排序均保留列表顺序；不靠对象键排序制造相等 |
| 简单字符串列表 | Tags 或重复行 | 适合禁用套路、标签、必要事实；逐项校验 |
| 枚举、布尔、数值 | Select、Toggle、带单位数值输入 | 不把 false、0、空串、null 混为一谈 |
| 长正文/模板 | 大文本编辑区、变量插入提示 | 正文是文本；不强行拆成键值表；转义展示变量 |
| JSON Schema | 递归属性表/编辑器 | 属性名、type、required、enum、范围、items、子对象逐项配置 |
| 开放对象或未来扩展 | 类型化键值编辑器与递归节点 | 保存未知键、类型、顺序语义；不支持的节点只读，不静默丢弃 |
| 正式事实、冻结快照、审计/评审结果 | Infolist、表格、证据卡、差异 | 逐字段可读但不可直接编辑；沿用创建候选/新版本的服务动作 |

**Schema 无损要求**：明确支持子集并覆盖实际现存数据；对象、数组、嵌套 required/additionalProperties、nullable、枚举与约束需往返一致。对于 oneOf/$ref 等尚不支持的真实数据，不得打开再保存后丢掉关键字；显示不能编辑的节点及原因，保留原值或阻止保存。高级 JSON 仅为折叠的导入/导出/诊断入口，不能替代日常可编辑字段。切换高级输入先校验再映射，失败不覆盖表单。服务端仍执行完整契约校验。

**Prompt 字段映射**：key/stage/language/reason 为基本信息；content.purpose 为用途；content.body 为模板正文；variable_schema/output_schema 分页签递归编辑；capability_requirements 为能力字段；examples 为重复样例；variables/output 依据各自 schema 渲染；required_facts 为字符串行。expected_version 等并发令牌由页面维护，不要求作者手填。

**路由映射**：Prompt/文风/主模型为实际版本选择器，展示版本与状态；fallbacks 为有序可批准列表；parameters 使用已验证能力对应的字段；mode 明示离线/真实但不启用本轮未授权能力。

**文风映射**：genre、voice.pov/tone/pace/description；forbidden_patterns、licensed_examples；rubric 按维度分行编辑描述和阈值；max_revision_rounds 数值；样章/评分/预期结果逐项维护。历史发布版本只读，保存新版本、测试、发布、退役分开动作。

**候选提取映射**：events、dependencies、knowledge、relationships、foreshadows 分成页签和重复行；字段必须从 ExtractionContract 与当前服务实际校验导出清单，不凭截图臆造。事件关联用实体/章节/前序事件选择器；证据支持原文片段与偏移定位；确认仍是离线候选，不能伪造正式事件。
