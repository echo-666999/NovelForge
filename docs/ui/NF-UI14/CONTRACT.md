# NF-UI14 工作台生产读取契约

范围：既有书级工作台与摘要接口。仅新增只读投影及现有页面导航；不新增迁移、生成引擎、自动操作、真实模型或中文分词。总览本轮不接入新投影。

- 权限先经 NovelIntentService，再在所属作者的小说行共享锁内读取。正式版本只查询当前活动 revision，核对 committed 提交、同书章与正文映射及 body_hash；映射总数、起止章序必须与游标构成连续前缀。缺失或矛盾不回退候选/其他基线。
- `production_state`：uninitialized（没有基线）、ready（包括合法空根零章）、unavailable（活动来源不完整）。基础查询异常由页面显示可重试错误，不能渲染零值或空态。
- `committed_chapters`：正式前缀；`next_chapter`：前缀之后实际存在的章骨架，不代表生成资格。`formal_versions` 最多读取当前页100章。
- 章节评审：只显示该正式提交绑定的历史评审。`review_issues` 为这些历史评审保留问题的数量，不是当前未解决数；不混入新候选、其他书或其他基线的评审。
- `index_lag`：活动基线已提交意图中未登记派生任务或尚未complete的数量；不表示时长、向量完整度或真实语义质量。Worker在线状态和终局准备度保持null，并显示未接入。
- `recent_run`：本书最新历史运行，有精确入口与冻结state_version；明确不是活动基线继续资格。不选择其他书的运行，也不将旧运行状态映射成当前生产状态。
- 今日费用按账本既有UTC请求发起日统计；币种分组、十进制文本，不做浮点运算或换汇。未知实际金额保留null，已核销小计与未核销风险预留分开。没有请求/币种是empty，不显示虚构金额0；有完整核销的实际零值才显示0。缺预算请求另计未知。
- 当前没有唯一的全书默认预算政策。`budget_remaining` 明确引用最近预算预留的policy/request，以该政策全书停止线减同币种全书累计风险占用。跨历史运行费用不消失；这只是参考，不承诺新运行额度。存在超预留对账问题及缺预算历史请求时显式提示。
- 入口：阅读、导出、运行、评审、正式提交、正式记忆与恢复链接到既有同书页面；只打开页面，不自动写入。真实生成保持禁用。暂停/继续由现有恢复台选择实际运行后核验，不保留无对象的伪操作按钮。
- 归档书可查看历史；目标页面原写入鉴权和门禁保持。没有基线仍可打开阅读/导出页面查看真实空态，不能据入口可见性推断存在可导出正文。

新增PHP类及方法沿现有中文注释约定。视觉复用DESIGN.md的Section、State、Table和Filament按钮，不增加CSS、图表或平行组件体系。
