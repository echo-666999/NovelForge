## 既有行为与后续任务

直接文档脚本有两项本轮实测、前后均存在的限制：Redis存在时虽然拒绝执行，但Laravel启动后的异常处理返回码为0；错误DB_URL在更早的启动错误诊断里会回显包含虚构探针凭据的URL。后者测试使用的是虚构值，文档只保存回显布尔值，不保存完整栈或凭据。普通artisan入口的既有脱敏测试仍通过，不能把本问题扩大为已确认的全部命令入口缺陷。

按“只做格式、保持守卫与复现行为不变”的本轮边界，未修改上述状态码/诊断逻辑；独立新增**NF-UI19 文档复现入口拒绝状态码与诊断脱敏**为todo。它不阻碍本轮格式通过，也不能因格式通过就宣称全部安全行为验收完成。
