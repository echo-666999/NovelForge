## 公共实现与数据边界

- `x-nf.story-select` 将旧视图**已授权且已经渲染**的 option 槽转成统一选择控件：DOMDocument 按 UTF-8 解析，关闭网络加载，保留实际 value（含0）、中文与转义。没有新增选项查询，不推断其他书的记录。所有标签再次由 Blade 转义。
- 单选复用 UI04/UI05 的 `x-nf.select`，原有 Livewire 属性和默认值保持；多选为逐项复选框，仍绑定原数组，不用整段 JSON 或逗号拼接替代。
- 固定对象/列表编辑沿用原生 Filament 字段与 Repeater；文本类型的计划说明仍是文本。只读历史、证据、校验与比较使用既有 value-table/value-comparison；不要求作者编辑历史 JSON。
- 公共 Field、Section、Table 与状态外壳；短字段桌面两列、手机一列；表格只在具名局部区域横向滚动；错误保留输入，加载期间给出状态提示。
- 树是普通列表与展开/定位按钮；没有伪称实现完整 ARIA tree 键盘协议。冻结判定只读复现现有 PostgreSQL 约束范围并缓存单请求结果，数据库仍是最终守卫。
- 未改应用服务、数据库、路由、API、授权与不可变协议。PlanningCandidates、正文编辑等 NF-UI07 范围未推进。全量历史分页/引用检索的既有局限不在本任务扩张。
