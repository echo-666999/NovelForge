# NF-B06 创作导航与工作台基础：实施与验收

日期：2026-10-23（Asia/Shanghai）。本轮仅实施 NF-B06，新增代码包含中文注释。不推进 C/F 等后续业务，不调用真实模型，不处理中文分词。

## 交付范围

创作总览替换默认账户仪表盘；新增小说工作台及 A04 的 GET /api/v1/novels/{novel} 只读摘要。小说列表标题、建书完成和复制成功后进入对应工作台；原始要求、蓝图、五层结构、世界人物、章节场景计划及工作台共用同书导航。URL 明确携带小说 ID，不使用全局“当前书”会话变量，因此打开不同书的多个标签页不会串书。

本轮不新增数据库表或迁移，不改动 B01–B05 的写服务、规划规则、冻结历史或正式状态，不向开发库写入测试小说。没有部署额外服务或修改供应商配置。

## 真实数据与状态定义

WorkspaceService 复用 NovelIntentService 的作者/管理员权限以及 RollingPlanService 的实时门禁，读取最新封存计划和已有冻结窗口。摘要在同一只读业务事务内持有小说共享行锁，与既有写服务的小说行锁配合，避免同一摘要混入两次规划变更。

| 内容 | 数据来源与含义 |
| --- | --- |
| 当前书、目标、字数策略 | novels 的实际字段；摘要只返回明确白名单，不暴露原始输入全文或 settings |
| 待决定要求 | 当前 requirement_versions 中尚未 accepted/waived 的条目；冲突保留为待处理 |
| 最近批准蓝图 | 最近 blueprint_approvals 对应的版本标识与 hash；显示为批准记录，不单独断言当前可用 |
| 最新滚动计划 | 最新 sealed rolling_plans 的版本、窗口、passed、ready/frozen/blocked/stale；复用 B05 当前依赖检查 |
| 有效冻结章数 | 仅统计当前 report.passed=true 的冻结窗口章序并集，避免重复计数；过期冻结记录仍留在历史，但不计作当前有效 |
| 缺项列表 | 无要求、待决定、无批准蓝图、无世界设定、无计划、B05 原样阻塞及待冻结提示；每项有同书处理入口 |
| 章节表 | 当前章节标题、章序、工作成熟度、窗口门禁或冻结状态、规划问题数；共享阻塞会计入窗口内相应章节，不冒充评审问题数 |
| 尚未接入指标 | canonical_baseline、committed_chapters、next_chapter、review_issues、today_cost、budget_remaining、worker_heartbeat、index_lag、ending_readiness、recent_run 均为 null |

工作台摘要 planning_status：archived 优先；其后 needs_decision、planning_blocked、planning_frozen。planning_frozen 只表示当前所展示规划窗口的有效状态，不等于全书规划全部冻结、可调用模型或正文成品通过。generation_eligible 固定为 false。章表保存状态 skeleton/detailed 与派生 ready/frozen/blocked/stale 分开，不回写小说存储状态。

费用未知不能显示0元；正式章数未知不能用规划章数替代；下一正式章不能按工作树或 state_version 猜测。终局准备度、运行、Worker 和索引指标当前不做服务健康检查，不显示伪造心跳或成功率。

## 页面与交互

| 页面 / 区域 | 字段、筛选、动作和状态 |
| --- | --- |
| UI02 创作总览 /admin | 小说、题材、中文存储状态、目标章数、最近更新时间（上海时区）、打开工作台；按 updated_at DESC/id DESC 稳定排序；状态、更新日期范围筛选，默认25条，可选10/50/100 |
| 总览空态 | 无书时引导“创建第一本小说”；有书但筛选无结果时明确显示“没有符合条件的小说” |
| 总览生产区域 | 明确费用、预算、正式章数、Worker、索引和最近运行未接入；下方小说更新时间表不伪装成最近运行记录；继续上次任务/异常/账单当前不可用 |
| UI04 工作台 /admin/novels/{id}/workspace | 当前小说及导航、真实规划计数、字数策略、最近批准蓝图、最新滚动窗口、待决定与缺项列表、规划章节表、生产动作禁用原因 |
| 章表 | 全书章序排序；章范围、规划状态、仅有规划问题筛选；默认25条，可选10/50/100；使用范围筛选查看近期章节。评审等级/正式版本尚未接入，不提供虚假筛选结果 |
| 同书导航 | 工作台、原始要求、蓝图与终局、五层结构、世界与人物、章节场景计划、切换小说、创作总览；固定显示书名/ID与正式基线“尚未接入” |
| 建书 / 复制 | 保留原有创建和复制服务；成功跳转到新书工作台，复制不回到原书；小说列表保留原来的编辑、归档和恢复动作 |
| 错误与加载 | loading 文案、刷新/安全重试；读取异常不显示成空列表，内部异常不展示给作者；非法筛选可重置；权限错误保留403/404，不伪装成无数据 |
| 生产动作 | 生成下一章、连续范围、暂停、继续、阅读器、导出显示为禁用，附未接入原因；不注册假的启动动作或弹窗 |
| 归档 | 工作台可读、显示归档；提示从小说列表恢复。相关页面原有写权限门禁不改变 |

已有创作入口归入“创作工作台”导航组。暂未实现的阅读器、生产、记忆或运维功能没有伪造菜单入口。正式启动配置/预计成本/停止条件弹窗、最近运行、费用与任务状态按 NF-F01/C07 接入。

## 接口契约

`GET /api/v1/novels/{novel}`：同源会话、管理员与小说所有权校验，返回 data/request_id/version=v1。未登录401、非管理员403、无权/不存在404、参数错误422。只读，不要求幂等键，不创建命令、计划、检查或运行记录。

查询参数：from/until 为章序（1..100000，支持单边范围）；status=skeleton/detailed/ready/frozen/blocked/stale；issues_only 为布尔；page≥1；limit 为10/25/50/100，默认25。from和until都提供时校验范围。返回 novel、navigation、planning_status、pending_decisions、blueprint、plan、planning_counts、blockers、chapters 分页元数据、production、generation_eligible 和 unavailable_reason。技术错误码在页面折叠详情中展示，主提示为中文。

总览由同一只读服务在 Filament 内调用，不新增需求外的总览公共API。日期筛选按 Asia/Shanghai 日界转换为UTC，截止日期采用次日零点之前，避免丢失当日最后时刻。

## 测试与实际结果

**NF-B06基础范围已实现并通过自动化验证。** 最终完整回归：140项，139通过、1项跳过、755断言。唯一跳过为既有中文分词服务器测试，本轮未处理。

新增 WorkspaceTest 10项，在实际 PostgreSQL 隔离测试库 novel_forge_test 执行，覆盖：

1. 首次无书与有书无匹配结果的不同空态，总览真实HTTP渲染。
2. 摘要缺项、全部未接入指标为null、读取前后novel/novel_commands不变。
3. 六个同书页面导航、甲乙书切换及返回，不产生跨书链接。
4. 未登录401、非管理员403、无权书404、错误筛选422。
5. 真实B05计划ready→frozen→要求变更后的stale；有效冻结计数10→0，始终不可生成。
6. 非法筛选与注入读取异常不伪装为空列表，不泄露内部异常内容。
7. 归档工作台可读与恢复提示、总览状态/日期筛选。
8. 总览10条分页与稳定顺序，无重复行。
9. 只填结束章的单边范围及错误筛选重置恢复。
10. Livewire真实建书与复制动作后跳转到正确的新书工作台。

完整回归包含既有B01–B05服务、PostgreSQL约束与真实并发进程测试，以及专用测试Redis的隔离探针。所有业务夹具仅在测试库运行，HTTP禁止未登记外部调用。开发时发现的结束章单边筛选误拒绝已修复后重跑完整套件。

Pint仅检查本轮9个变更PHP文件；前端npm run build通过，原有fontaine可选字体优化提示仍保留；git diff --check通过。API与后台路由及页面已由自动化HTTP/Livewire测试验证。未运行真实模型、未执行数据库迁移；测试Redis在验证结束后关闭。
