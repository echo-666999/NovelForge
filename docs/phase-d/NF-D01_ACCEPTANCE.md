# NF-D01 事件、证据与可回放故事状态

日期：2026-10-24。授权范围为 D01 服务与测试；不推进 D02、E03、E06，不调用真实模型，不安装中文分词。

## 交付与契约

`app/Services/StoryStateService.php` 提供以下内部应用服务。所有入口验证管理员及小说归属；没有新增 HTTP、Filament 或生产生成入口。

| 方法 | 范围与返回 | 关键门禁 |
| --- | --- | --- |
| registerArtifact | 将不可变运行产物中的完整 `text` 注册为来源，返回十进制字符串 ID；重复注册返回同一来源 | 校验产物归属及规范 JSON 哈希，持小说行锁 |
| evidence | 保存来源版本、哈希、码点半开区间及精确引文 | UTF-8、换行规范化、范围/引文/哈希检查；数据库触发器也复核 |
| propose | 追加候选事件和对应状态补丁，同一事务保存 | 具体实体版本已批准、实体未停用、角色持有者有效；禁止跨类别修正 |
| assertSource | 将提取事件与调用方明确指定的来源版本及哈希比较 | 相同引文字面也不能把旧事件重绑到新正文；历史证据保留 |
| replay | 从显式事件清单重放到指定章，返回六类状态、状态哈希、待确认清单、候选局部游标 | 拒绝重复 ID、重复叙述位置、缺失/已撤销的修正目标；逐条验证事件、补丁及证据 |
| rebuild | 从原始事件重新生成快照和实体投影 | 书行锁及事务原子替换派生记录，不读取摘要或信任旧缓存 |

六类状态为 `fact/belief/rumor/lie/inference/hidden_truth`。角色说法要求 `holder_id`，客观事实和隐藏真相不带持有者；各类使用独立容器，置信度不能把说法升级为事实。`uncertain` 事件只进入待确认列表，不应用到状态。隐藏真相仅存在管理员内部候选结果中；不得将完整结果直接作为后续 POV 上下文，知识和可见性过滤由 D02/D06 实施。

每个候选事件只表示一个实体属性变化，补丁由服务确定性派生，不能独立写入用户提供的补丁。`set` 新增，`replace/revoke` 必须指定同实体、同属性、同类别及同持有者的前置事件。替代移除旧贡献并加入新贡献；撤销移除目标贡献，不自动恢复已被替代的祖先事件。事件和证据不更新、不删除；修正理由及作者保留。状态附带来源事件、证据、引入章序和原始故事时间。

章内顺序为显式正整数，回放按 `(chapter_sequence,narrative_order)` 排序。输入 ID 顺序不影响结果；相同流的重复位置拒绝。JSON 对象键排序、列表顺序保留、浮点数拒绝，PG JSONB 重排不改变哈希。仅接收 PHP 标量/数组，不接收未经解析的 JSON 文本或任意对象。事件内容哈希不含数据库生成的 ID，状态哈希包含证据和来源事件，因此不同提取事件即使文字相同也保留不同来源身份。

正文规范为 `body-lf-utf8-sha256-v1`：CRLF/CR 转 LF；不 trim、不 NFC、不替换标点；拒绝无效 UTF-8 和 PostgreSQL text 无法存储的空字节。`甲😀乙` 中 emoji 为 `[1,2)`；不是 UTF-16 单元或 UTF-8 字节区间。

## 数据库与迁移

迁移：`2026_10_24_000013_create_story_state.php`。

| 表 | 定位与约束 |
| --- | --- |
| source_documents | 当前只接受 artifact 类型；同书/同运行/产物复合 FK，产物唯一；完整规范正文和哈希不可变 |
| evidence_spans | 同书来源复合 FK；数据库校验范围、源哈希和引文；不可变 |
| proposed_events | 同书证据、实体与具体版本、持有者、修正目标 FK；六类事实、动作及修正约束；不可变 |
| proposed_state_patches | 每事件唯一补丁、哈希及同书 FK；不可变 |
| story_events | 不可变正式事件预备结构；`d01_formal_entry_closed CHECK(false)` 阻止所有插入 |
| state_snapshots | 候选流哈希 + 章序唯一；显式 `scope=candidate` 和局部游标；可重建 |
| entity_state_versions | 快照/实体唯一；同书复合 FK；随派生快照删除并重建 |

书内章位、正式基线叙述顺序、快照流与章序、实体快照均有 B-tree 索引/唯一索引。全部新增表和字段有实际 PostgreSQL 中文备注，测试读取系统目录验证。

**与 A04 的分阶段映射**：A04 字典是最终目标。当前 chapter_versions、canonical_revisions、canonical_commits 尚不存在，所以正式事件预备列不建立虚构 FK，也绝不允许写入。E06 必须先补齐真实复合 FK 和 Canonical Commit 门禁，再替换关闭约束；不得仅删除约束。D01 快照和实体投影以候选快照归属，未冒充正式 revision/state_version。来源注册当前只有一个明确 artifact FK；章节/场景/事件/规则等来源由后续模块扩展强类型 FK 与匹配约束，不能填无外键数字指针。现有逻辑字典保留最终目标，本记录说明当前物理落地差异。

## 验收覆盖

| 验收点 | 实测方式 |
| --- | --- |
| 同事件同章状态哈希一致 | 打乱输入顺序后比较完整回放结果；多章历史查询 |
| JSONB 键顺序不误判 | 嵌套对象键顺序变化同内容哈希；列表顺序变化异哈希；实际 PG JSONB 落盘后回放 |
| 信念不能改变客观存亡 | 六类事件同一属性，事实 alive、信念 dead，分别读取 |
| 待确认不升级 | uncertain 只列入 pending；正式 state_version 不变 |
| Unicode 证据 | emoji 正例；错误范围/引文/哈希/非法编码反例；不裁剪末尾空白或合成 Unicode |
| 旧正文提取隔离 | 新产物正文保留相同 emoji，旧事件绑定新版本仍被拒绝；原证据仍可读 |
| 追加修正 | 替代/撤销保留历史章状态；缺失目标、跨类别修正、重复位置被拒绝 |
| 投影可重建 | 人为将快照改为伪造摘要并删除实体投影，重建恢复原哈希；原事件未变 |
| 数据库门禁 | 直接 UPDATE/DELETE 来源事件补丁失败；伪造引文/偏移/哈希直接 INSERT 失败；实体版本 FK 不符失败；正式 INSERT 被硬门禁拒绝 |
| 权限与原子性 | 他人小说、跨书来源/事件、停用实体拒绝；失败提案不留下事件或补丁 |
| 中文备注及迁移 | 查询 pg_class/pg_attribute；既有空库回滚与重迁测试纳入第 13 个业务迁移 |

自动化与迁移实际结果在本文件末尾记录，不将设计描述当成已执行验收。
