## 已实现行为

- 按阶段、小说、候选运行分支、窗口场景、POV 和状态版本组装。校验场景属于冻结窗口、POV 对应场景的已批准人物版本、计划对应运行冻结大纲。已有运行保留启动时的路由、变量、能力、价格和预算身份，不能借组装改变运行配置。
- 顺序：系统任务与输出 Schema；需求快照、蓝图引用及全局已批准核心实体/世界规则/POV 硬约束；章与场景计划；状态基线标识及候选事实；角色知识与关系；到期/逾期/回收前五章伏笔及终局；最近候选正文；活动记忆及检索资料；文风样例与负面清单。
- 作者计划、隐藏真相、作者记忆和候选正文均有独立作者区标识，不作为角色可知信息。POV 使用 D02 截止章重演结果，并通过 D04 校验同书、同分支的事实及获知证据来源。没有 D02 知识版本时不推断角色已知事实。
- 关键事实直接读取 D04 证据事实清单，到期伏笔直接读取 D03 账本，终局直接读取批准蓝图；均不依赖向量调用或 Top K。最新两条候选正文和全部活动摘要直接查源，可补足索引延迟；无正式章位证明的候选正文只进入作者区。检索使用 D05 的分支/活动代次/来源过滤及降级说明。
- 每项记录来源类型/ID/版本、来源片段哈希、文本哈希、类别、分区、强制标记、分数/通道排名、Token 估算、纳入原因、裁剪原因、最终顺序和完整文本。排名小数转为文本后封存，遵守项目规范化协议。最终 Prompt 单独保存及 SHA256 绑定；清单另有规范化哈希。
- 容量按最终拼接文本（包括分区标题与分隔符）计算：输入＋最大输出＋适用单列推理预留＋安全余量。included 不再额外加推理，separate 只加一次；缺单列预留或明确计量冲突阻塞。只针对冻结主模型，不自动换路由或启用备用模型。
- 无对应供应商 tokenizer，使用 UTF-8 字节保守估算，actual_tokens=null、误差未知。此方法不代表供应商精确计量或中文分词；消息封装开销须由安全余量覆盖，真实发送前仍需模型适配验收。
- 去重限于同分区可选副本；容量不足先移除低相关可选记忆，再淘汰其他可选条目。保留每条被裁剪原文，不截断硬约束、场景计划、关键事实、到期伏笔和终局。强制内容仍放不下则 over_capacity。未生成新压缩摘要，避免绕过 D04 事实保留门禁。
- 清单只追加，数据库触发器禁止更新或删除，复合外键绑定同书/同运行/同阶段。重放同一幂等键只返回首次内容，输入变化拒绝。重组另建清单，不改写 generation_steps 冻结输入、不创建或自动执行模型尝试。
- 历史文本不因来源停用而改变；书级输入/状态变化或运行取消时 current_status=stale。新组装缺失强制事实有效来源时 missing_required。所有清单 formal_usable=false、real_model_eligible=false。

## 接口和 UI23

- GET `/api/v1/generation-steps/{step}/context`：最新清单；`manifest` 指定历史，配合 `compare` 比较同阶段两次组装。
- POST 同路径：同源会话、CSRF、管理员与小说所有权；Idempotency-Key 必填。输入 scope=candidate、plan_id、scene_id、pov_id、configuration、billing、safety_margin、expected_version、reason；context_id 和 search 可选。configuration 为冻结 route_version_id 与 variables；billing 沿用 C05。search 只接受 build_id、profile_id、query、limit、vector；其他范围字段由服务固定。
- formal 请求返回 FORMAL_CONTEXT_UNAVAILABLE，不返回候选资料作为正式上下文。不存在清单返回404；非法场景/POV和配置身份变化明确报错。
- 后台“上下文检查器”选择已有阶段、查看最新/历史清单、按强制项/类别与记忆类型/通道/裁剪原因过滤、定位冻结原文、查看不含供应商凭据的最终 Prompt、比较两次文本、追加重组清单。硬约束没有人工移除入口。
- 当前运行只有 test.echo 测试支架；检查器不会建立生产运行或调用模型。真实生成发送、正式正文/基线及初始角色知识接线仍待后续明确授权任务。
