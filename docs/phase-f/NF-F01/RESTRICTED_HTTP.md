# NF-F01 受限HTTP适配与离线故障（2026-10-30）

## 实现及边界

新增 OpenAiResponsesHttpAdapter，使用既有网关的预算预留、冻结输入、请求身份和证据存储。ResponsesAdapter 仅标记线协议，不授予调用权限。既有供应商非Fake门禁保持关闭。

HTTP请求构造采用完整 /v1/responses 地址、POST JSON与Bearer认证，接口约定核对了 [OpenAI官方文本生成文档](https://developers.openai.com/api/docs/guides/text)。本轮未变更模型、价格或业务Schema。

受限传输措施：

- HTTPS、精确主机白名单、443端口；拒绝用户信息、查询参数、IP字面量等不安全端点。
- 校验所有DNS结果为公网单播，混合内网结果整体拒绝；固定本次连接IP并保留主机TLS验证。
- 禁用代理、重定向、连接复用及自动重试，只允许HTTPS协议。使用HTTP/1.1并关闭Expect协商；SingleAttemptCurlFactory限制一次调用只能创建一个句柄，阻断Guzzle底层失败回卷重试。
- 总超时与连接超时必须为正整数，连接超时不大于总超时，总超时不超过600秒。
- 接收流最多保留1 MiB加1字节；超过1 MiB立即中断。超限保存的是原始前缀，不能称为完整原始响应。
- 禁止自动解压，要求identity编码，避免解压后的无界膨胀。
- 原始正文或故障前缀继续脱敏、加密、计算摘要；不保存含密钥的异常文本。
- HTTP错误即使返回HTML、空正文或非法JSON，也保持HTTP错误类别。
- 断连或超时标为unknown，不将可解析前缀当成功；缺失Usage保留预算风险预留。同一逻辑键不再次传输。
- 未收到响应头时HTTP状态存null，不虚构服务器状态；无有效Retry-After时不虚构退避值。

## 本轮授权限制

适配器send同时要求testing环境和显式Guzzle MockHandler；没有模拟处理器，即使testing环境也拒绝执行。CurlHandler接线已保留，但处于不可达的关闭门禁后。不能通过环境切换或配置启用供应商绕过本轮限制。

本轮所有HTTP故障由内存处理器模拟，无真实DNS、TCP、TLS或供应商请求。公网IP固定、TLS和超时参数已离线检查，但实际网络执行效果仍需后续授权验证。无DDL、无配置发布、无设定批准、无开发库变更。
