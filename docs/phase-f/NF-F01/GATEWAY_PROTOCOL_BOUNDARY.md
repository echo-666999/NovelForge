# NF-F01 网关协议边界（2026-10-30）

## 本轮范围

在不开放真实传输的前提下，把 Responses 请求构造、响应解析和业务结果还原接入网关的隔离测试路径。规划、正文、提取、评审、修订执行器统一通过 ProviderGateway::businessOutput 读取业务结果。

- 请求证据保存实际传输结构；响应证据保存原始字节，继续沿用密钥脱敏及加密存储。
- 读取证据验证内容摘要。业务结果读取绑定原始输入、模型及协议转换版本；失败、未知、隔离响应不得消费。
- 新协议幂等身份包含 optional-envelope-v1，不能与旧 Fake 请求串用逻辑键；旧请求哈希保持兼容。
- optional-envelope 的 absent 还原为缺省字段，业务结果继续由既有阶段完成事务写入 generation_artifacts，不覆盖原始响应。
- OpenAiResponsesFixtureAdapter 仅用于 testing 环境，不持有端点或密钥，不执行网络请求。非 Fake 供应商及非测试环境门禁保持关闭。
- 无 DDL、无开发库配置变更、无供应商启用、发布或真实模型请求。
